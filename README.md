# sim-drama-prompt-kit · 仿真人漫剧提示词五件套

一套面向**仿真人（写实）AI 漫剧 / 短剧**的提示词工程 skill：把"剧本"和"AI 出画面"之间那一层，做成可校验的机械流程。

```
剧本/文案
  ├─① 角色卡 → 锁脸、锁鞋、锁姓名标签的参考图
  ├─② 场景卡 → 无人、匿名、四要素的纯净空镜
  └─③ 分镜器 ─┬─ 10 秒四段（有台词）
               ├─ 15 秒四段（有台词）
               └─ Veo 8 秒×4（无对白纯演绎，字段强锁）
```

## 为什么用它

仿真人漫剧崩得最狠的四个点，这里都有硬锁：

| 崩点 | 对应机制 |
|---|---|
| 同一角色跨镜变脸/换装/没鞋/被裁脚 | 角色卡：全身不裁切、鞋履强锁、姓名标签位置锁 |
| 场景里莫名出现路人，场景名无法区分 | 场景卡：绝对真空与匿名、场景名≥4 字、四要素 |
| 一大段概括，画面和文案对不上 | 35–50 字一拆、数量守恒、TEXT_ANCHOR → TEXT_BINDING |
| 提示词被判违规 / 台词时段镜头乱推拉 | 六类违禁词表 + 降级替换、台词时段镜头固定 |

## 快速开始

1. 角色：`templates/role-card.md` → 粘贴原文 → 得到人物清单与逐角色生图提示词 → 用户确认角色
2. 场景：`templates/scene-card.md` → 粘贴文案 + 风格要求 → 场景清单 + 场景设定表
3. 分镜：按交付时长选 `storyboard-10s.md` / `storyboard-15s.md` / `veo-8s.md`
4. 自检：过一遍 `references/07-自检与常见坑.md` 的 12 条

## 安装为 DSH 技能

```powershell
Copy-Item -Recurse . "$env:USERPROFILE\.dsh\skills\sim-drama-prompt-kit"
```

装好后在 DSH 会话里说"仿真人漫剧提示词 / 分镜头提示词 / 角色卡提示词"即可命中。

## 五条铁律

1. 文案锚定：35–50 字一拆、分镜数=文案条数、一句原文一个镜头、没写的动作不加
2. 六维一致：人物 / 时空 / 物品 / 动作承接 / 台词合规 / 敏感过滤
3. 结构固定：`[时间段] 镜头:[景别]+[镜头]+[核心动作]；音效:[主音效]+[环境音]；[台词/画外音]`
4. 合规降级：过程镜 → 结果镜 / 反应镜 / 对峙镜 / 带离镜 / 画外后果确认
5. 输出纪律：全中文引号、场景信息一字不改、video_prompt ≤500 字符、只映射真实出场角色
