# 06 · 合规降级替换表

## 六类高危词
1. 血腥暴力（重点）：血液飞溅、喷血、鲜血淋漓、血池、断头、内脏出血、分尸、碎尸、斩首、砍头、挖眼、掏心、剥皮、凌迟、虐杀、酷刑、断肢、爆头、穿刺、撕咬、屠杀、灭门、焚尸、尸横遍野、血肉模糊、骨裂、脑浆、残肢断臂
2. 裸露低俗：全裸、半裸、袒胸露背、露脐、露私密部位、一丝不挂、赤膊、性感暴露、挑逗性裸露、低俗姿势、衣不蔽体
3. 色情与性暗示：色情、淫秽、嫖娼、卖淫、性交易、一夜情、通奸、乱伦、恋童、兽交、约炮、撩骚、床上戏、艳舞、脱衣舞、乳房、阴部、阴茎（直白描述）
4. 封建迷信（强化）：血腥祭祀、活人献祭、血咒、尸变、僵尸吸血、恐怖化妖魔鬼怪
5. 危害公序良俗：自残、自杀、暴力教唆、聚众斗殴、黑帮火拼、恐怖袭击、校园暴力
6. 敏感宗教/政治：邪教仪式、极端宗教、分裂、恐怖组织、反动、颠覆

## 降级手法
| 手法 | 说明 |
|---|---|
| 结果镜 | 只拍事后状态，不拍过程 |
| 反应镜 | 拍旁观者/受害者表情 |
| 对峙镜 | 用站位与视线替代肢体冲突 |
| 带离镜 | 用"被带离"替代"被掳走" |
| 画外后果确认 | 用声音与目击者转述交代结果 |

## 词表替换
| 高风险 | 低风险 |
|---|---|
| 掳走 | 带离 |
| 暴打 | 冲突升级 |
| 刺伤 / 砍伤 | 受创 / 受阻 / 失手后退 |
| 嘴角流血 | 紧咬下唇，衣领有红痕 |
| 武器特写伤人 | 作为剧情物件简要出现，不特写使用过程 |

## 原则
保留主线因果，丢掉高风险细节；改写而非删除。原文冲突强时优先改写为：对峙、停顿、后退、阻拦、带离、震惊、转身、松手、失手、情绪崩溃、落泪、凝视、僵住、被迫分开。
