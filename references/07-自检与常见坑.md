# 07 · 自检与常见坑

## 交付前 12 条自检
- [ ] 角色卡：全身不裁切、鞋履可见、姓名标签在脚底正下方居中、纯白背景、单人
- [ ] 场景卡：无人、无人名、场景名 ≥4 字、四要素齐、Prompt 以"不能出现其他人，无人，纯场景"开头
- [ ] 文案拆分：每句 35–50 字、语义完整
- [ ] 分镜数 = 文案条目数
- [ ] 字段仅 3 个：panel_index / prompt / video_prompt
- [ ] 全中文引号，无英文引号
- [ ] video_prompt ≤ 500 字符
- [ ] 角色映射 100% 且不含未出场角色
- [ ] 场景信息一字不改
- [ ] video_prompt 含"衔接前置"段落
- [ ] 台词时段镜头固定不推拉；非说话角色无张嘴/喉部动作
- [ ] 违禁词全部降级替换，过程镜改结果镜/反应镜

## 高频坑（原文自带对照）
| ✗ | ✓ |
|---|---|
| 林辰在会议室突然出现咖啡罐（上镜在格子间） | 林辰揉眼蹭墨痕（延续上镜断笔沾墨状态） |
| 写入未出现的"王经理"角色映射 | 仅写画面实际出现角色 |
| "林辰嘴角流血" | "林辰紧咬下唇，衣领有红痕" |
| 台词时镜头切换/推拉 | 台词时段固定镜头，标注"镜头稳定，不推拉" |
| 把"暗中挑拨""心防崩塌"直接写进 ACTION | 改成可见行为：递茶、避开视线、攥紧袖口 |

## 原模板的六处矛盾（照抄会出错）
1. 15 秒模板残留"每个画面为10秒" → 见 03/04 时间轴
2. 10 秒模板 [3-6 秒] 与示例 [3-4 秒] 冲突 → 用 3-4
3. "严禁输出括号说明"但示例满篇括号 → 理解为模板占位符不留在成品
4. video_prompt ≤500 字符 vs 长台词长动作 → 删形容词，绝不删 TEXT_BINDING 与人名
5. 分镜示例三条子文案共用同一段"女孩跪地"镜头 → 只示范格式，不示范内容
6. "图片提示词不映射人物" vs 角色卡要姓名标签 → 分镜 prompt 不带人名映射；角色卡是另一条线
