# 02 · 场景卡（电影级纯净场景）

## 目标
产出**无人、匿名**的场景设定图与原样可复用的 SCENE_TAG（中文场景名）。
场景资产是空镜，给生图用；人物名只出现在视频提示词里，两者不混用。

## 五条后台规则
1. **绝对真空与匿名**：画面严禁出现任何人影；描述文字严禁出现角色人名。
2. **场景命名法则**：≥4 字，用具体修饰词增加辨识度，禁止单一名词。
3. **四大核心要素**：环境类型 / 具体时间（精确到时段与光线）/ 空间氛围 / 视觉主要特征。
4. **Prompt 开头固定**："不能出现其他人，无人，纯场景，" 并带 `no humans, empty, landscape only`。
5. **输出控制**：不输出括号说明文字，直接给成品。

## 两步输出
### 第一步：场景提取清单
`编号. 场景全称｜核心氛围｜建议色调`

### 第二步：场景设定表
```
场景名称：（四字以上独特命名）
画幅构图：横向 16:9 电影级场景设定图，极高画质，纯净无人的空间，写实电影风格
视觉风格：（用户指定风格），极致细节
场景描述：
  环境类型：…
  时间时刻：…
  空间氛围：…
  主要特征：材质、核心物件、前中后景标志性元素（严禁写角色姓名）
Prompt（直接复制）：不能出现其他人，无人，纯场景，…，no humans, empty, landscape only
```

## 命名改写示例
| 泛名 | 改写 |
|---|---|
| 遇见路夜景 | 老城遇见路梧桐夜街 |
| 医院急诊诊室 | 医院深夜急诊诊室 |
| 古建园林 | 古建园林回廊 |
| 蓝湖景区 | 蓝湖薄雾栈桥景区 |

## 检查
- 场景描述里有没有偷偷写"李老根站在…"（有人名即失败）
- 生成的图里有没有人影/动物/车辆剪影当作主体
- SCENE_TAG 是否与分镜模板里的 `SCENE_TAG` 逐字一致（不一致就等于换场）
