# 03 · 分镜 10 秒版

## 适用
单格 10 秒、含台词与画外音的短剧/漫剧分镜；Seedance、即梦一类 5–10 秒模型最贴。

## 时间轴
```
[0-3秒] 镜头:[景别]+[镜头]+[核心动作]；音效:[主音效]+[环境音]；[台词/画外音]
[3-4秒] 镜头:[景别]+[镜头]+[细节特写]；音效:[关键音效]
[4-8秒] 镜头:[景别]+[镜头]+[情绪特写]；音效:[氛围音]；[画外音/沉默说明]
[8-10秒] 镜头:[景别]+[镜头]+[下一镜铺垫]；音效:[过渡音]
```
（原始模板正文写 [3-6 秒]，示例写 [3-4 秒]；以 3-4 为准，否则总长凑不满 10 秒。）

## 拆解规则
- 内容以 **35–50 字**一拆，单句必须语义完整。
- **数量守恒**：文案条目数 = 分镜数；禁止自行合并或阜行拆分。
- 一条文案内部若再拆，用 1-1 / 1-2 / 1-3 编号，并保留"原文案 / 子文案"两行。

## 六维一致性
| 维度 | 判定 |
|---|---|
| 人物一致 | 只写画面真实出现的角色，未出现绝不映射 |
| 时空一致 | 时间（晨/午/晚）、地点、光线与上一镜无缝衔接 |
| 物品一致 | 关键道具位置状态延续上一镜 |
| 动作连贯 | 新镜起始动作承接上一镜结束状态 |
| 台词合规 | 仅当前说话角色有张嘴动作；台词时段镜头固定不推拉 |
| 敏感过滤 | 违禁词自动替换中性词 |

## 四步法
STEP1 场景锚定（时间/地点/人物三角）→ STEP2 连续性检查（比对上一镜结尾）→ STEP3 台词植入（仅当含对话）→ STEP4 敏感扫描替换。

## 3 秒决策原则（执行前必检）
人物是否齐全？场景是否连贯？有无违禁？任一不满足，立即中止重推。

## 输出
三字段：`panel_index` / `prompt`（生图，内不含人物映射，场景信息一字不改）/ `video_prompt`（≤500 字符，含角色映射与"衔接前置"段）。
引号：全中文引号。
