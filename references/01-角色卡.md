# 01 · 角色卡（仿真人角色形象提取）

## 目标
从小说/文案里抽出**全部**出场人物，每人一条生图提示词，产出可直接锁脸的参考图。
只出角色，不出剧情，不出场景。

## 提取指令
```
根据我发给你的这篇文章，帮我整理出所有角色形象，需要包含人物性别、穿着、脸部特征、年龄、身高以及人物性格。
根据提供的小说原文，推导出文中出现过的人物，人物可能有多种代称，要囊括文中提到的所有人物，包括我。每个人物包含名字、代称（多个代称用逗号分割）、形象描述三个字段。
人物形象必须包含：具体年龄、性别、发色、发型、眼睛颜色、脸部特征、上身服装、下身服装、身高；每个输出结果必须有不一样的着装，需要更好分辨。
要求：不要表格；全部为正面站立全身图片；图片风格为写实电影感（并在提示词中加入"写实电影感风格"这句话）；人物背景为纯白背景。
```

## 硬锁（少一条就会返工）
| 项 | 要求 | 必写句 |
|---|---|---|
| 全身 | 头顶到脚底完整入镜，四肢完整，不裁切；占画面高 68%–78% | "完整全身站姿，头顶到脚底完整入镜，双脚完整可见，四肢完整，不裁切" |
| 鞋履 | 穿鞋不赤脚、鞋完整可见、鞋型与身份时代一致、颜色协调；裤摆裙摆不得遮鞋 | "双脚穿着完整鞋履，鞋子清晰可见，不赤脚，鞋型与服饰及时代设定一致" |
| 姓名标签 | 只在脚底正下方中央出现一次，垂直对齐中心线，独立标签区，不偏移不贴边不覆盖人物 | "画面最底部设置独立中文姓名标签区，仅在人物脚底正下方中央显示『角色名』，文字严格与人物中心线垂直对齐，除姓名外无任何其他文字" |
| 构图 | 单人、居中、正面或轻微三分之二侧角、中性静态站姿、禁止夸透视与变形 | — |
| 背景 | 纯白 #FFFFFF，无场景无他人无物件无 UI 无 logo 无水印 | — |

## 输出格式（每个角色一段，不分点）
```
1）角色名：
（一整段可复制图片提示词）
```

## 检查
- 是否遗漏只出现代称的角色
- 两个角色是否撞衫（撞衫会导致跨镜认错人）
- 姓名标签是否可能被生成到肩膀或头顶（写清"脚底正下方"是关键）
- 角色性格是否写进气质描述（影响表情稳定性）
