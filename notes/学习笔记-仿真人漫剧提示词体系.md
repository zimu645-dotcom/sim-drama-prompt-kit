## 0. 一句话结论

这不是五份提示词，而是**一条资产流水线被切成了三个输出版本**：

```
剧本/文案
  ├─① 角色卡（仿真人提示词.txt）      → 角色参考图（锁脸、锁鞋、锁姓名标签）
  ├─② 场景卡（剧本场景提取.txt）      → 纯净空镜（无人、匿名、四要素）
  └─③ 分镜器 ──┬─ 10 秒版（4 段式时间轴）  ┐
                ├─ 15 秒版（4 段式时间轴）  ├→ panel_index / prompt / video_prompt
                └─ Veo 8 秒×4 版（[1]-[8] 强结构）┘
```

三个版本**共用同一套底层纪律**：文案锚定 → 一致性校验 → 时间轴硬切 → 违禁词降级 → 输出自检。

## 3. 五条共通铁律（提炼自全部文件，可当验收标准）

### 铁律 1｜文案锚定（TEXT_ANCHOR）
- 文案 **35–50 字**一拆，拆出的单句必须**语义完整**（不能半句悬空）。
- **数量守恒**：章节文案有 N 条 → 必须输出 N 个分镜；禁止按原文长短自行合并或阜行拆分。
- 一句原文 = 一个镜头的动作依据；**原文没写的动作不许加**（不许补"奔跑/跪下/施法/抱住/喊叫"）。
- 用外部可校验的账本表达：`TEXT_ANCHOR`（本段原文句群）→ `TEXT_BINDING`（本镜对应哪一句小句）。

### 铁律 2｜六维一致性
| 维度 | 要求 |
|---|---|
| 人物一致 | 只写画面真实出现的角色；未出现角色绝不写进角色映射/CAST |
| 时空一致 | 时间（晨/午/晚）、地点、光线与上一镜无缝衔接 |
| 物品一致 | 关键道具（钢笔/背包/煤油灯）位置与状态延续上一镜 |
| 动作连贯 | 新分镜起始动作必须承接上一镜结束状态（LAST_STATE） |
| 台词合规 | 只有当前说话角色有张嘴动作；台词用中文引号""；台词时段镜头固定不推拉 |
| 敏感过滤 | 违禁词自动替换为中性词，保持剧情逻辑 |

### 铁律 3｜结构固定（不许自由发挥格式）
- 镜头行格式：`[时间段] 镜头:[景别]+[镜头]+[核心动作]; 音效:[主音效]+[环境音]; [台词/画外音]`
- 景别纪律：**多用近景/特写/大特写，不用远景，少用中景**（10/15 秒版）；Veo 版用 WS/MS/MCU/CU，单段景别跳跃 ≤2 级，禁直接跳 ECU。
- 音效分层：主音效 / 环境音 / 氛围音 / 过渡音，逐段递进。
- 输出字段锁死三件：`panel_index / prompt / video_prompt`，多一个少一个都算失败。

### 铁律 4｜合规降级（不是删除，是改写）
- 违禁词六大类：血腥暴力 / 裸露低俗 / 色情与性暗示 / 封建迷信 / 危害公序良俗 / 敏感宗教政治。
- 降级手法：**过程镜 → 结果镜 / 反应镜 / 对峙镜 / 带离镜 / 画外后果确认镜**。
- 官方替换示范：
  - "林辰嘴角流血" ✗ → "林辰紧咬下唇，衣领有红痕" ✓
  - "掳走" → "带离"；"暴打" → "冲突升级"；"刺伤/砍伤" → "受创/受阻/失手后退"
- 危险物（刀/法器）只作剧情物件，不特写使用过程。

### 铁律 5｜输出纪律
- 全中文；**禁止英文引号 "**，统一中文引号"…"。
- 场景信息**一字不改**地嵌进 prompt（原文场景锁）。
- `video_prompt ≤ 500 字符`。
- Veo 版额外：`Match provided character reference images only.` 必须原样保留；画面零文字（无字幕/贴纸/logo/水印/字母数字）。

## 4. 分镜器完整执行清单（10 秒 / 15 秒版，逐条可勾）

**拆前**
1. 提取时间 / 地点 / 人物三角要素（STEP1 场景锚定）
2. 比对上一镜结尾：动作、台词、物品位置（STEP2 连续性检查）
3. 3 秒决策原则三问：人物是否齐全？场景是否连贯？有无违禁？

**拆中**
4. 35–50 字一拆，句子完整
5. 每条子文案生成一个分镜；有子拆分则编号 1-1 / 1-2 / 1-3
6. 台词只在原文含对话时植入（STEP3），且用中文引号
7. 敏感扫描与替换（STEP4）

**拆后自检（7 条）**
- [ ] 字段数 = 3（panel_index / prompt / video_prompt）
- [ ] 全中文引号，无英文引号
- [ ] video_prompt ≤ 500 字符
- [ ] video_prompt 中人物 100% 映射角色信息库，且不含未出场角色
- [ ] prompt 内含原始场景信息，一字不改
- [ ] video_prompt 含"衔接前置/承接上一镜"段落
- [ ] 分镜数量 = 文案条目数

**高频坑（原文自带对照）**
| ✗ 错误 | ✓ 正确 |
|---|---|
| 林辰在会议室突然出现咖啡罐（上镜在格子间） | 林辰揉眼蹭墨痕（延续上镜断笔沾墨状态） |
| 写入未出现的"王经理"角色映射 | 仅写入画面实际出现角色 |
| "林辰嘴角流血" | "林辰紧咬下唇，衣领有红痕" |
| 台词时镜头切换/推拉 | 台词时段固定镜头，标注"镜头稳定，不推拉" |

## 5. Veo 版 [1]-[8] 八段结构（逐字段说明）

| 段 | 名称 | 关键内容 |
|---|---|---|
| [1] | GLOBAL RULES | 一行全大写开关串：STYLE=韩漫风二次元影视化 / RATIO=9:16 / TEXT_FREE=ON / NO_DIALOGUE=ON / SILENT_PERFORMANCE_ONLY=ON / NAME_BINDING_LOCK=ON / TEXT_ANCHOR_LOCK=ON / ONE_MOVE_PER_SHOT=ON / SHOTS_DEFAULT=2 / OTS_SAFE_DOF=ON / NO_ECU=ON / CAST_LOCK=ON … |
| [2] | FOCAL SUBJECT | 默认 1 个中文主名，最多 2；严禁 3 人同时做焦点 |
| [3] | CAST | 只写中文主名列表，不许省略人名 |
| [4] | SCENE LOCK | SCENE_TAG / Time / Key Light Direction / Overall Tone / **Blocking Anchor**（谁左谁中谁右、谁前景谁中景谁背景、朝向、相距几步）/ Population Anchor: Exactly CAST only |
| [5] | CONTINUITY | TEXT_ANCHOR / 拆段提示（超载时第一行写）/ From LAST_STATE / Current State（只写可见可听）/ Silent Performance Conversion（原文对白转无声表演）/ Safety Adjustment / End Hook |
| [6] | TIMELINE | Info Beats 3–6 条（每条带人名、对应原文小句）+ Shot 01/02，每镜含 TEXT_BINDING / CAMERA / LINK / NAME_BINDING（10 项）/ SILENT_LOCK / ACTION / AUDIO |
| [7] | FINAL VEO PROMPT | 风格、角色、场景锁 + 零文字 + 只允许环境音与拟音 + 姓名绑定 + 匹配角色参考图 + 体积化电影感（接触阴影/遮蔽关系/视差/重量感/缓入缓出）+ 非图解化冲突 + 严格按 [5][6] 执行 |
| [8] | 合规替换 | 高风险词 → 低风险叙事词对照表 |

**NAME_BINDING 十问**（每镜必填）：谁在左/中/右、谁在前景/中景/背景、谁先动作、谁后动作、谁是主情绪承载者、谁只反应。
**动作句句式**：`人物名：动作……；人物名：动作……；人物名：反应……`

**运镜纪律**（Veo 版专属，10/15 秒版没有）
- 每段 8 秒、每镜**只允许 1 个主运镜**（ONE_MOVE_PER_SHOT）；每秒最多 1 个动作变化 + 1 个镜头变化。
- 同主体连续表演可 MATCH_CUT / MOVE_CONTINUE / MOTION_INHERIT；主体切换必须明确 CUT；**不许既写分镜又写"同一镜头连续不切"**。
- 0.0–1.2s 必须开场连续摄影，先读清空间关系与接地感，再进冲突。
- 默认 HOLD_180 保持空间可读；过肩镜头守 OTS_SAFE_DOF（前肩虚、后脸清、不遮关键部位）。
- 三人同镜：只允许 1 人明显跨位移动，其余原地小幅反应；写明主行动者 / 被作用者 / 静态锚点人物。

**无声演绎（本版核心，与 10/15 秒版最大分歧）**
- 原文对白**不发声**，转译为"无声情绪动作锚点"：停住、抬眼、避开视线、呼吸发紧、眼眶泛红、手指收紧、后退半步、嘴唇发颤但不说话、泪水滑落。
- 允许极轻微唇部颤动与呼吸开合，**不得形成清晰说话表演**。
- 音频只允许 realistic ambience + foley/SFX；无 BGM、无人声、无旁白。

## 7. 对接本项目《遇见路》婚礼漫剧资产库：差距与动作

| 环节 | 现状 | 五件套要求 | 要补的动作 |
|---|---|---|---|
| 角色 | 有定妆图与"头肩锁脸照" | 全身不裁切、鞋履强锁、姓名标签区、人物占画面高 68–78% | 用角色卡模板重出 5 个角色提示词，补"双脚穿着完整鞋履…"与"画面最底部独立姓名标签区…"两句硬锁 |

| 分镜 | data_v3.py 是镜头数据，无文案锚定列 | 35–50 字一句、TEXT_BINDING、NAME_BINDING、数量守恒 | 给 SHOTS 加 `text_anchor` / `name_binding` 两列，输出严格三字段 JSON |
| 视频 | seedance 5s/10s | 10 秒四段式 / Veo 8 秒×4 强结构 | 主用 10 秒版；需要高一致性叙事段（如秀禾、求婚）改用 Veo 8 秒×4 |

**注意一个容易混用的边界**：场景卡要求"严禁出现任何人名、画面无人"，而分镜卡要求"把人物名写进镜头"。两者**不冲突也不通用**——场景资产是空镜（给生图用），人物名只出现在视频提示词里。

## 9. 原文矛盾 / 坑清单（照抄会出错，先记下来）

1. **15 秒版残留 10 秒表述**（"每个画面为10秒"）→ 以 0-4/4-8/8-12/12-15 为准。
2. **10 秒版 [3-6 秒] 与示例 [3-4 秒] 不一致** → 用 3-4，否则总长超标。
3. **"严禁输出任何括号内的说明文字"，但示例里满是括号**（[角色信息]、[风格要求]）→ 理解为"模板占位符不要留在成品里"。
4. **video_prompt ≤500 字符 vs 长台词长动作** → 超限时删形容词与重复描写，**绝不删 TEXT_BINDING 与人物名**。
5. **分镜示例三条子文案共用同一段"女孩跪地"镜头** → 示例只示范格式，不是内容正确的示范；不要照抄内容。
6. **"图片提示词内不需要映射人物" vs 角色卡要写人名标签** → 分镜的 prompt（生图）不带人名映射；角色卡是另一条线，才有姓名标签。
7. **"数量严格控制"与"35–50 字一拆"**：数量守恒指**与文案条目数相等**，拆分发生在"一条文案 → 一条分镜"之内，不是自由发挥加镜。

## 10. 我理解的这套方法论内核

把"创作"拆成三段可校验的机械动作：
**先立资产（人、景），再立账本（句、名、位、时），最后才生成画面。**
所有提示词里那些 `XXX_LOCK=ON` 的本质，是让"模型自由发挥的空间"被压到只剩表演细节——这正好是我们做婚礼漫剧（角色要像本人、场景要像实景、镜头要连得上）时最缺的那层约束。
