# 模板 · 角色卡

## 第一步：让模型出人物清单
```
根据我发给你的这篇文章，帮我整理出所有角色形象，需要包含人物性别、穿着、脸部特征、年龄、身高以及人物性格。
根据提供的小说原文，推导出文中出现过的人物，人物可能有多种代称，要囊括文中提到的所有人物，包括我。每个人物包含名字、代称（多个代称用逗号分割）、形象描述三个字段。
人物形象必须包含：具体年龄、性别、发色、发型、眼睛颜色、脸部特征、上身服装、下身服装、身高；每个输出结果必须有不一样的着装，需要更好分辨。
要求：不要表格；全部为正面站立全身图片；图片风格为写实电影感（并在提示词中加入"写实电影感风格"这句话）；人物背景为纯白背景。

文章：
{{粘贴原文}}
```

## 第二步：每个角色一条生图提示词
```
{{角色名}}：写实电影感风格，{{年龄}}岁{{性别}}，{{发色}}，{{发型}}，{{眼睛颜色}}，{{脸部特征}}，上身{{上装}}，下身{{下装}}，身高{{身高}}，{{性格}}气质。
完整全身站姿，头顶到脚底完整入镜，双脚完整可见，四肢完整，不裁切；人物占画面高度 68%–78%，上方与下方留白充足，脚底下方留出少量空白余量。
双脚穿着完整鞋履，鞋子清晰可见，不赤脚，鞋型与服饰及时代设定一致。
画面最底部设置独立中文姓名标签区，仅在人物脚底正下方中央显示"{{角色名}}"，文字严格与人物中心线垂直对齐，除姓名外无任何其他文字，姓名不与人物重叠、不偏移、不贴边。
正面或轻微三分之二侧角，角色居中，中性静态站姿，手臂自然下垂，五官与轮廓清晰，禁止夸张透视与变形，禁止跪坐蹲姿。
纯白背景 #FFFFFF，无场景、无其他人物、无多余物件、无 UI、无 logo、无水印。
```

## 第三步：确认后进入分镜
固定回一句：`请确认角色；如需修改角色，请直接指出。确认后我再输出视频提示词。`
