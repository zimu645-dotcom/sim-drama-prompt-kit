# 模板 · 分镜 10 秒

```
根据旁白和对话拆分分镜头。分镜脚本提示词要求如下：

【内容镜头一致性原则】内容以 35–50 个字以内进行一次分镜头拆分，要求拆分出的单句文案内容要完整。
示例：内容"（原文）"→ 拆成两段/三段子文案，每段 35–50 字、语义完整。

【核心目标与原则】图片提示词内不能带有乱七八糟的文字标识，不需要给出角色映射；视频提示词中前后分镜必须有关联性，需要思考上个画面，保证情节连贯，人物、场景、时间必须在相邻分镜中保持高度一致性。

【重要】视频提示词一定要有角色标签映射语句，一定要包含所有视频提示词中应该出现的角色；没有出现的角色不能写在角色标签映射中。

【十分重要】文案中对话放入视频提示词用中文引号标注。必须包含镜头、环境音 / 对话 / 细微肢体动作发声，合适的地方给出解说（白话文）。
注意：不是当前角色台词，不需要有张嘴、喉部动作等疑似发声动作；嘴唇动作需与台词同步；台词时段镜头固定，不切换、不推拉。
【重要】不要重复生成上下分镜已有的镜头，和上下分镜的故事情节要连贯。

【3秒决策原则】人物是否齐全？场景是否连贯（时间 / 地点 / 光线与上一镜一致）？有无违禁内容？任一不满足立即中止重推。

【六维一致性准则】
人物一致：严格匹配角色信息库，未出现角色绝不写入
时空一致：相邻分镜时间（晨/午/晚）、地点、光线无缝衔接
物品一致：关键道具位置状态延续上一镜
动作连贯：新分镜起始动作承接上一镜结束状态
台词合规：仅当前说话角色有张嘴动作，台词用中文引号
敏感过滤：自动替换违禁词为中性词，保持剧情逻辑

【分镜生成四步法】STEP1 场景锚定（时间/地点/人物三角）→ STEP2 连续性检查（比对上一镜结尾动作、台词、物品位置）→ STEP3 台词植入（仅当文案含对话）→ STEP4 敏感扫描替换。

镜头+音效+台词（严格按时间轴）：
[0-3秒] 镜头:[景别]+[镜头]+[核心动作]；音效:[主音效]+[环境音]；[台词/画外音]
[3-4秒] 镜头:[景别]+[镜头]+[细节特写]；音效:[关键音效]
[4-8秒] 镜头:[景别]+[镜头]+[情绪特写]；音效:[氛围音]；[画外音/沉默说明]
[8-10秒] 镜头:[景别]+[镜头]+[下一镜铺垫]；音效:[过渡音]

【遵循要求】
1. 全中文输出；禁止英文引号，统一中文引号
2. 标点格式统一，不混用中英标点
3. 视频提示词严格按参考案例结构，每个画面 10 秒
4. 场景信息给出的内容一字不改放到指定位置
5. 图片提示词内不需要映射人物
6. 景别多用近景、特写、大特写，不使用远景，少用中景
7. 拆分文案内容要合理

【数量控制】为每条文案生成一个分镜，输出总数必须等于文案条目数；禁止按原文长短自行合并或拆分。

【违禁词】血腥暴力 / 裸露低俗 / 色情与性暗示 / 封建迷信 / 危害公序良俗 / 敏感宗教政治，一律替换为中性词。

【输出自检】字段仅 3 个：panel_index / prompt / video_prompt；全中文引号；video_prompt ≤ 500 字符；人物 100% 映射；prompt 含原始场景信息一字不改；video_prompt 含"衔接前置/承接上一镜"段落。

【输出格式】
分镜头1
原文案:"…"
子文案:…（有拆分则 1-1 / 1-2 / 1-3）
[0-3秒] 镜头:…；音效:…；…
[3-4秒] 镜头:…；音效:…
[4-8秒] 镜头:…；音效:…
[8-10秒] 镜头:…；音效:…
场景:…（一字不改）

文案：
{{粘贴旁白与对话}}
```
